video-director skill: code-rendered video (HTML/Canvas → MP4) with gates and QA scripts

win4r/video-director (MIT, 330 stars, 8 commits, created 2026-10-28) is a Claude Code skill where the model writes animation in HTML/Canvas/SVG/Three.js/GSAP/Remotion and it is rendered frame by frame to MP4. It ships no shot library. It holds 13 principles with their reasons, per-film dials (clock, continuity, register, text policy), a build contract and a phased workflow with a gate at each phase. Two scripts: check_timeline.py validates the plan (timeline.json) before any code; qa_video.py measures the finished film: hook text size and contrast, frame 0, flashes, cuts, freezes, loop seam, loudness, silences, contact sheets (--beats timeline.json). Evals: 3 briefs with graders. Round 1: 28/28 vs 25/28 without the skill, blind graders 2–1, about 2× time and tokens. Round 2: 30/32 vs 26/32 for the previous skill version, 3–0. One run per configuration; the authors call it "a direction, not a measurement". Newer sections on characters, revisions and live pages are unevaluated.

You already have a Remotion pipeline and the montage and quality-gates skills, so what is new is measured checking of what the model cannot watch or hear, plus plan validation before code. Dependencies: ffmpeg, Python with numpy and Pillow, Playwright, optional faster-whisper (you already have whisper). First step: git clone https://github.com/win4r/video-director.git && cp -R video-director/video-director ~/.claude/skills/, then run python3 video-director/scripts/qa_video.py film.mp4 --out qa/ on any finished clip of yours.

Take for your setup
  • Run qa_video.py on finished Remotion-pipeline clips (hook, frame 0, loudness, silences, loop seam) and wire it in as a gate before delivery?
  • Take check_timeline.py and the timeline.json template to validate the plan before render in the montage skill?
  • Copy the round-2 hook rule: text and call to action on screen by 3 s, sound off, with measured size and contrast — add to our video skills?
  • Reuse their evals setup (3 briefs, graders, blind comparison with vs without the skill) for our own skills?

rea-video: an agent skill that breaks a video down shot by shot into filmed, AI-generated or coded

rea-video (Apache-2.0, 1492 stars, repo created 2026-10-29) is a toolkit for Claude Code and Codex. The repo ships `.claude-plugin/`, `skills/rea-video/`, `AGENTS.md` and `CLAUDE.md`. It cuts a video into shots, splits the audio into voice, music and effects, and judges how each shot was made: filmed, AI-generated, coded (a Remotion template), screen-recorded, or avatar-driven. It relies on measurable evidence: frame cadence, sensor noise, whole-frame panning, AIGC tags in metadata; for audio it computes BPM and key. Hard evidence outranks visual impression, and conflicts go to the agent for a visual check. Output: a summary such as "41% AI video + 59% code UI, 8 s of real screen recording, library music at 122 BPM", a remake plan (what to film, generate, code), SRT/ASS captions and `report.html`. The plan respects the target video model's limits (clip length, reference count).

Accuracy, weighted by shot duration: tools only gets 98.3% on the tuning set and 99.6%/98.9% on the holdout. On WeChat re-encoded files it drops to 88.6%; with Gemini vision it is 99.6%, with agent visual review 100%. It needs ffmpeg and Python 3.10+; a vision model (Gemini or Doubao) is optional. Detailed docs are in Chinese for now; the example reports are in English.

For you: Remotion, montage and image-create already exist in your setup, but reverse analysis of a video does not. First step: tell the agent "Install https://github.com/JuneYaooo/rea-video, then break down this video: /path/to/video.mp4" and compare the report against a clip you know. The agent passes `--lang` to set the report language.

Take for your setup
  • Install rea-video as a plugin/skill and run it on your own Remotion clip to check whether it detects "code/template" shots and caption timing correctly.
  • Borrow its rule "hard evidence (metadata, frame cadence) outranks visual impression, conflicts go to a visual review" and add it to the montage skill when analyzing references.
  • Use the `rea_video/capabilities/` tables (limits of video, image and audio models) as a reference for image-create and video plans: clip length, reference count.
