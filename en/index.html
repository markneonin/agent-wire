Command Code sells discounted per-token model access through a $5-a-month membership

MOAT costs $5/month billed yearly ($60), or $10 month to month. It isn't flat-rate: you pay for tokens from credits at member prices, with no 5-hour, weekly or monthly caps. There's no router fee, and 105 models are listed. Per 1M tokens (input/output): GLM-5.3 $0.49/$1.54 (65% off), GLM-5.3 Flash $0.045/$0.15 (70%), off-peak DeepSeek V4.1 Flash $0.06/$0.24 (60%), Kimi K3 $1.80/$9 (40%). Some discounts are temporary, and there are no refunds. HN is skeptical: in one comparison, discounted DeepSeek V4.1 Flash on OpenRouter was $0.0507/$0.2028, cheaper than MOAT. Another user estimated that on this model membership pays off from about $15–20 a month. People also ask where requests are processed and call "unlimited" misleading.

For you, it's a possible source of cheap open models for opencode and other external tools: the docs say MOAT works in Claude Code, Codex and OpenCode. ZDR is off by default. Enable it with CMD_ZDR=1 in the CLI or the x-cmd-zdr: 1 API header. Not every model has it, and on some it costs extra. The MOAT and ZDR pages don't say where data is stored. First step: compare prices for your models, and if they pay off, point a client at https://api.commandcode.ai/inference/v1 (OpenAI format) or https://api.commandcode.ai/inference (Anthropic).

Take for your setup
  • Your vendor-review uses free opencode Zen models: add a paid GLM-5.3 reviewer through the MOAT API as a trial?
  • If MOAT goes into scripts or reviews that touch private code, require the x-cmd-zdr: 1 header and first check whether the chosen model has ZDR and what it costs?
  • Before paying, price your monthly token volume at MOAT rates plus the membership fee, then compare with OpenRouter and the provider's direct rates, including off-peak ones?

UX Pilot released a free skill: your agent designs the UI on their canvas, then builds it in your code

uxpilot-ai/frontend-design-skill is an Apache 2.0 skill for Claude Code, Cursor and other agents (per the note: repo created November 25, 194 stars). Before writing a design brief, it reads your project's product, audience, routes, colors, fonts and copy. Screens are generated in UX Pilot, and a canvas link lets you compare, edit and comment on them. The agent shows each screen in chat and fixes common problems such as low contrast or clipped text. It builds the screens you pick with your existing components and checks them against the design. It needs the UX Pilot MCP server and a sign-in. The README says a free account is enough to start, but design runs use credits, so the skill asks before each one. I found no separate pricing or limits sections.

You already have a frontend router skill. What's new is an external canvas where you choose a design before any code is written. It does tie you to a third-party service, and your project brief probably goes to UX Pilot. First step: `npx skills add uxpilot-ai/frontend-design-skill`, then `claude mcp add --transport http uxpilot https://mcp.uxpilot.net/mcp`, then run `/mcp` and sign in. Instead of npx, you can copy `skills/ui-design` into `~/.claude/skills/`. Example prompt: "Redesign our pricing page. Keep our brand colors."

Take for your setup
  • The skill reads the project's product, audience, routes, colors, fonts and copy before the brief: add that as a required step in your frontend skill?
  • It shows each screen in chat and fixes low contrast and clipped text: add that visual check to your frontend skill?
  • It checks the built UI against the chosen design: make that comparison a separate step after implementing a mockup?
