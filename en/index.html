super-sidebar plugin: a sidebar with an agent tree and task flow for Claude Code and Codex

claude-super-sidebar (Zafer-Liu, v0.2.0, Apache 2.0, 155 stars, created 2026-10-20) shows the main agent and its subagents in one tree. Each node shows status (running, waiting, completed, failed), model, mode, role, tokens, context usage, elapsed time and tool-call count, with details expanding in place. Below that is a task flow: operations grouped into stages, up to 30 recent steps, and each new user request starts a fresh flow. Verification claims are labeled assistant-reported, and "Operations completed" only means tools ran. Everything is computed locally, with no extra LLM call.

In Claude Code it is a native plugin pane: lifecycle hooks (hooks/register.tsx) plus a parser over session.messages() and ui.render. It needs a Claude Desktop Code host with the early-access pane API and a matching CLI; it was built against engine 2.1.299. For Codex there is a separate local dashboard on Node.js 22.18+ that reads JSONL from ~/.codex/sessions every 2 seconds (that format is not a stable API). Limits: plan extraction in Claude is unverified, no history across sessions, subagent metrics can be unavailable, and native validation was not rerun.

For you: you run nested leads, background agents and Workflow scripts, and a per-node tree with tokens and context fills a blind spot, while your observability skill looks only after the fact. The API is early, so treat it as an experiment. First step: claude plugin marketplace add Zafer-Liu/claude-super-sidebar, then claude plugin install super-sidebar@super-sidebar, start a new session and type /super-sidebar. Codex dashboard: npm run codex -- --cwd "/abs/path", then open http://127.0.0.1:4317.

Take for your setup
  • Install super-sidebar and watch a Workflow/task-lead tree: does it show tokens and context per subagent?
  • Borrow their pattern of labeling verification claims as assistant-reported and separating 'tools ran' from 'verified': add this rule to our process skill or a Stop hook?
  • Run the Codex dashboard on 127.0.0.1:4317 next to use-codex and vendor-review to watch the second opinion live.
