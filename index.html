agent-autoloop: фоновый хаб, который сам запускает Claude Code/Codex по событиям и шлёт карточку, только когда нужно решение

agent-autoloop (MIT, создан 3 ноября 2026, 1845 звёзд) — самохостинг-хаб на Node 24 для CLI-агентов: Claude Code, Codex, ACP и generic `command`-агент. Правила лежат в `~/.agent-autoloop/rules.json`: `when` (cron, GitHub webhook вроде `issues.opened`, HTTP), `to` (агент), `cwd`, `prompt` или `skill`, опционально `parallel`. Агент отрабатывает один раунд и выходит. Если нужно решение (деструктивное, платное, внешнее действие), он кладёт в конец ответа блок `agent-autoloop` с ключами `ask`, `notice`, `resolve`, `later`, `events`. Хаб шлёт карточку (десктоп-уведомление, Feishu, webhook-шаблоны для Slack/Discord), процесс не висит и токены не тратятся. После ответа та же сессия возобновляется. Если JSON сломан, хаб просит переписать только блок. Ядро ~1650 строк без зависимостей, event sourcing, внешний текст (тело issue) передаётся как данные, а не вклеивается в промпт, цепочки событий ограничены 8 уровнями. Есть PR-конвейер по лейблу `deliver`: ревью, CI, merge, проверка деплоя. Ограничения: нет веб-UI, только macOS/Linux, Slack/Discord проверены лишь на моке, потеря питания не тестировалась, автор советует API-ключ для частой автоматизации.

С `/schedule`, `/loop` и Stop-хуками у тебя пересечение: это локальный аналог, но с event-триггерами и паузой «без процесса» до ответа человека. Новое для тебя — протокол карточек-вопросов в конце ответа и защита от prompt injection через разделение данных и инструкций. Первый шаг: `curl -fsSL https://raw.githubusercontent.com/KKKKhazix/agent-autoloop/main/install.sh | sh`, затем `agent-autoloop try`.

Что взять себе
  • Протокол «агент заканчивает ответ блоком ask/notice/later» — добавить в наш loop-design и в Telegram-бота: агент сам просит решение кнопками вместо блокировки сессии.
  • Лимит глубины цепочки событий (8 уровней) и логирование вместо запуска — добавить такой предохранитель в loop-design для /loop и /schedule.
  • Правило «текст из issue/внешних источников передаётся как данные, события с полями cwd/agent/access отклоняются» — вписать в CLAUDE.md и скиллы, которые читают внешний текст (avito, chatting).
  • Повтор запроса на переписывание только битого финального JSON (без переделки работы) — применить в скриптах с `claude -p --json-schema`.
