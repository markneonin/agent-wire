01GitHub01.11

cheap-ag: MCP-сервер, где Opus планирует, а дешёвая модель пишет код в worktree и сдаёт только то, что прошло тесты

cheap-ag (npm `cheap-agent`, MIT, TypeScript) — MCP-сервер и плагин для Claude Code. Opus формулирует короткую задачу, дешёвая модель (DeepSeek и др. через OpenCode Go, OpenRouter, DeepSeek, Command Code) работает в отдельном git worktree и обязана написать тест, который падает до правки и проходит после. Тесты сервер гоняет сам, не веря отчёту модели. Прошедшая работа ложится незакоммиченной, коммитов и push нет. Если дешёвая модель не справилась, шаг забирает Sonnet (`takeover: "sonnet"`) или сам Opus (`"self"`, до 15 вызовов инструментов). Лимит шагов — `limits.max_turns`, по умолчанию 25.

Замеры на SWE-bench Verified с Opus 5.5: фича 154k против 57k токенов Opus (−63%), 7 обычных багов 1.6M против 655k (−59%, 7/7 у обоих), 9 сложных 3.0M против 1.3M (−55%, 6/9 против 7/9). Автор честен: на мелких задачах выгоды почти нет, а проверка Opus каждого зелёного результата стоила втрое больше токенов и ничего не нашла. «50x» из заметки — не измерение, цель автора: $20-план как $50–70.

Для твоего сетапа это тот же паттерн, что worktree на писателя плюс implementer, но с внешним дешёвым исполнителем и жёстким тестовым гейтом. Первый шаг: `npx cheap-agent`, выбрать OpenRouter, вставить ключ, проверить `claude mcp list`, в проекте выполнить `/cheapag:allow`, затем `/cheapag:status` для стоимости.

Что взять себе
  • Правило «дешёвый исполнитель обязан написать тест, красный до правки и зелёный после, а тесты гоняет оркестратор сам» — добавить в скилл feature-build/testing для implementer?
  • Не гонять Opus-ревью по каждому зелёному результату: автор намерил 3x токенов без находок — ограничить quality-reviewer случаями с упавшими или отсутствующими тестами?
  • Попробовать `/cheapag:hook on` на одном проекте и сравнить расход через `/cheapag:status` с текущим implementer на Sonnet.
  • Взять эскалацию «дешёвая модель → Sonnet → Opus с лимитом 15 вызовов» в наши agent-файлы как явную лестницу вместо ручного выбора.

Скилл reanimate для Claude Code разбирает анимацию покадрово, пишет её код и сверяет копию с оригиналом

reanimate — скилл для Claude Code (MIT, 548 звёзд, создан 29.10.2026). Берёт анимацию с живого сайта, записи экрана, mp4, gif или Lottie и воссоздаёт её в вашем проекте. Цикл такой: 1) запись в headless-браузере с фиксированным вьюпортом и fps: видео, кадры, CSS и Web Animations, позиции элементов на каждом кадре (для canvas/WebGL — трассировка GPU-вызовов на виртуальных часах); 2) спецификация: строка на элемент и свойство (старт, длительность, from/to, easing, stagger), «?» там, где значение ещё не прочитано; 3) код на том, что уже есть в проекте: CSS, Framer Motion, GSAP или three.js; 4) проверка: копия снимается так же, сравниваются тайминг, easing и пиксели, на выходе листы side-by-side; 5) правка самой большой разницы и пересъёмка, обычно 2–5 раундов, остаток с причинами уходит в отчёт.

Точность задаётся формулировкой: «clone this animation» — движение в пределах 80 мс; «pixel-perfect» — ещё и вид, ≤2% среднего расхождения пикселей. Заявлено: Vercel toolbar — 417 из 417 кадров идентичны, Resend cube — 0,11% пикселей, большинство клонов 30–90 минут. Нужны Bun 1.1+, macOS/Linux, ~250 МБ при первом запуске (ffmpeg, Chromium), ключи не нужны. Пружины подбираются по перерегулированию, не читаются из кода; сайты за логином и YouTube не записать.

Для вас новое — не сама генерация, а замкнутый цикл «снять → спецификация → собрать → снять копию → измерить» с числовым порогом; это шаблон для Remotion-пайплайна и любых UI-задач. Первый шаг: `npx skills add NiazMorshed2007/reanimate -g -a claude-code`, затем `/reanimate the hero entrance on https://example.com, into components/Hero.tsx`.

Что взять себе
  • Скилл сам проверяет результат числом: ≤80 мс по таймингу, ≤2% пикселей — добавить такой порог «снять копию и измерить» в frontend-скилл для анимаций?
  • Спецификация со знаком «?» для ещё не измеренных значений и ограничение в 5 раундов с отчётом об остатке — взять как шаблон в loop-design для циклов fix-until-green?
  • Попробовать reanimate на Remotion-пайплайне: снять эталонную анимацию с сайта и получить спецификацию по элементам и свойствам как бриф для сцены?
