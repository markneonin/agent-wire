Плагин super-sidebar: боковая панель с деревом агентов и потоком задач для Claude Code и Codex

claude-super-sidebar (Zafer-Liu, v0.2.0, Apache 2.0, 155 звёзд, создан 20.10.2026) показывает главного агента и субагентов одним деревом. Для каждого видны статус (running, waiting, completed, failed), модель, режим, роль, токены, использование контекста, время и число вызовов инструментов. Раскрываются детали на месте. Ниже идёт поток задач: операции группируются по стадиям, до 30 последних шагов, каждый новый запрос пользователя начинает новый поток. Заявления о проверке помечены как «со слов ассистента», «Operations completed» значит только выполнение инструментов. Всё считается локально, без лишнего вызова LLM.

В Claude Code это нативная панель плагина: lifecycle-хуки (hooks/register.tsx) плюс парсер по session.messages() и ui.render. Нужен Claude Desktop Code с ранним API панелей и CLI; разработано на engine 2.1.299. Для Codex отдельный локальный дашборд на Node.js 22.18+: раз в 2 секунды читает JSONL из ~/.codex/sessions (формат не стабильный API). Ограничения: извлечение плана в Claude не проверено, нет истории между сессиями, метрики субагентов бывают недоступны, нативная валидация не перепроверялась.

Для тебя: у тебя много вложенных лидов, фоновых агентов и Workflow, и дерево с токенами и контекстом по каждому узлу закрывает слепое пятно, а твой observability-скилл смотрит это постфактум. Это ранний API, поэтому ставь как эксперимент. Первый шаг: claude plugin marketplace add Zafer-Liu/claude-super-sidebar, затем claude plugin install super-sidebar@super-sidebar, новая сессия и /super-sidebar. Дашборд Codex: npm run codex -- --cwd "/abs/path", затем http://127.0.0.1:4317.
